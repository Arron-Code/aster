# Aster Caffe Premium App

Eine eigenständige Single-Page-App für ein Premium-Kaffeeprodukt mit gemeinnütziger Ausrichtung.

## Start

Öffne `index.html` direkt im Browser oder starte im Projektordner einen lokalen Server:

```powershell
python -m http.server 5173
```

Danach ist die App unter `http://localhost:5173` verfügbar.

## Inhalte

- Premium Landing Page für äthiopischen Rohkaffee
- Interaktiver Lot-Katalog mit Filterung
- Impact-Rechner für Gemeinwohl-Beitrag
- B2B-Anfrageformular mit lokaler Speicherung der letzten Anfrage
